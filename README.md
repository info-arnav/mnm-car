# Deep Forest 360° viewer

Open `index.html` in a browser. Drag or swipe over the car to rotate it; arrow keys also work. Use the top-right button for fullscreen.

The 72 optimized WebP frames come from `Deep_Forest.zip` in Downloads. Frame 73 was omitted because it repeats the starting angle. The viewer uses no external libraries or network calls.

To host online, upload this whole folder to any static web host, preserving the `frames` subfolder.
